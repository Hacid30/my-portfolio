# Héctor Hacid | Frontend Developer Portfolio

Personal web portfolio to showcase my projects, skills, and certifications as a Frontend Developer.

**[View Live Portfolio](https://my-portfolio-kappa-eight-59.vercel.app/)**

## Tech Stack

This project was built using modern tools from the React ecosystem:

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **UI Library:** [React](https://reactjs.org/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Deployment:** [Vercel](https://vercel.com/)

## Local Installation & Setup

If you want to clone and run this project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/Hacid30/my-portfolio.git
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the development server:
    ```bash
    npm run dev
    ```
4. Open http://localhost:3000 in your browser to see the result.
